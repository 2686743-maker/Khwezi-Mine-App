# Khwezi-Mine-App

Khwezi Mining Health, Safety and Equipment Monitoring Application.

## Run the app

Install the requirements and start Streamlit from this folder:

```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```

## Questions & Answers

After signing in, open **Questions & Answers** in the sidebar. Choose a category, then tap a question to calculate an answer from the app's data. Answers may include a chart and the underlying data table. The incident period filter applies to questions based on safety incidents; responses are calculated from the bundled data and do not require an external AI service.
